# ADR-0006：新版結構版本管理候選 Flyway

- 狀態：Proposed（待使用者選定）
- 提案／查核日期：2026-11-17（Asia/Taipei）
- 決策者／核准日期：待確認
- 主要任務：[Issue #4](https://github.com/xk2022/codex-xk-logistic/issues/4)
- 整體提案：[技術選型與資料接續建議](../TECHNOLOGY_AND_DATA_PROPOSAL.md)

## 背景與選項

候選為 Flyway、Liquibase 或其他可重現的版本化工具。既有規格偏向 Flyway，本庫仍未選定 migration 工具。Schema 版本管理與舊資料匯入是兩個工作；採 Flyway 不代表已核准搬遷或刪資料。

## 建議方案

建議 Flyway 作唯一的結構版本遷移入口，JPA 驗證映射；不以正式 ddl-auto=update 代替版本化 DDL。選定後依資料庫加入對應模組，由與 Boot 相容的組合管理版本。

## 影響與驗收

選定後需驗證空庫建立、版本升級、重複執行、歷史校驗與 JPA 映射；若另有舊資料匯入，按來源映射與試遷驗收處理。不可把修改已發布 migration 當正常修復；正式變更、回復及資料破壞操作依既有授權邊界。本輪未新增依賴或建立 SQL 檔。

## 依據與狀態

[Spring Boot DB Initialization](https://docs.spring.io/spring-boot/how-to/data-initialization.html)；[Flyway PostgreSQL 模組文件](https://documentation.red-gate.com/flyway/reference/database-driver-reference/postgresql-database)。僅完成方案與整合前提研究，未驗證相依解析或資料庫執行。
