## 背景與選項

候選為 Flyway、Liquibase 或其他可重現的版本化工具。既有規格偏向 Flyway，使用者現已採用 Flyway 作為結構版本管理工具。Schema 版本管理與舊資料匯入是兩個工作；採 Flyway 不代表已核准搬遷或刪資料。

## 已採用方案

採用 Flyway 作唯一的結構版本遷移入口，JPA 驗證映射；不以正式 ddl-auto=update 代替版本化 DDL。實作時依已選 PostgreSQL 加入對應模組，由與 Boot 相容的組合管理版本。

## 影響與驗收

實作後需驗證空庫建立、版本升級、重複執行、歷史校驗與 JPA 映射；若另有舊資料匯入，按來源映射與試遷驗收處理。不可把修改已發布 migration 當正常修復；正式變更、回復及資料破壞操作依既有授權邊界。本輪未新增依賴或建立 SQL 檔。

## 依據與狀態

[Spring Boot DB Initialization](https://docs.spring.io/spring-boot/how-to/data-initialization.html)；[Flyway PostgreSQL 模組文件](https://documentation.red-gate.com/flyway/reference/database-driver-reference/postgresql-database)。工具選擇已確認；相依解析與資料庫執行仍未驗證。
