## 後續D07決策（2026-11-17）

使用者已明確回答沒有必須保留的舊Truck客戶／訂單／照片，依[ADR-0007](ADR-0007.md)採M01全新啟用。本次不需它們的舊schema／映射／試遷輸入；PostgreSQL空庫、精確相依與新版備份仍待驗證。下文的來源未知保留為原技術採用時背景，不是目前D07狀態。

## 背景與選項

原選項為延續 MySQL 或改採 PostgreSQL。使用者現已採用 PostgreSQL 17 作為新版資料庫基準；技術採用當時，正式DB／來源與是否需遷移尚未知；本輪後續已採M01，L3來源門檻只在未來新增匯入需求時適用。

## 已採用方案

採用 PostgreSQL 17，開工前鎖定仍受支援的修補版。原採用紀錄當時尚未選定資料路線；本輪已依ADR-0007採M01，無所詢問舊資料匯入。若未來另提跨引擎匯入，才驗來源型別與業務語意；未操作現有DB。

## 影響與驗收

本次 PostgreSQL 官方頁列 17.12 與 17 系列支援期限 2029-11-08。若涉及跨引擎資料接續，另驗證 UUID、日期時區、小數、排序、唯一性、鎖語意與關聯；依 M01–M03 選定範圍，不自動搬遷。真實 DB 的空庫重建、交易回滾與資源競爭驗收待開工後執行。資料庫選擇不綁 ORM 或認證方式。

## 依據與狀態

[PostgreSQL 版本政策](https://www.postgresql.org/support/versioning/)；[L3 來源與技術門檻](../L3_LEGACY_AND_TECHNOLOGY.md)。支持年限與修補版本是查核快照，不是已部署版本。
