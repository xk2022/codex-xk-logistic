# ADR-0003：新版資料庫候選 PostgreSQL 17

- 狀態：Proposed（待使用者選定）
- 提案／查核日期：2026-11-17（Asia/Taipei）
- 決策者／核准日期：待確認
- 主要任務：[Issue #4](https://github.com/xk2022/codex-xk-logistic/issues/4)
- 整體提案：[技術選型與資料接續建議](../TECHNOLOGY_AND_DATA_PROPOSAL.md)

## 背景與選項

候選為延續 MySQL 或改採 PostgreSQL。新產品原先已有 PostgreSQL 17 候選及 Rotaract 參考方向；但現有正式 DB、資料擁有人與是否需遷移仍未知，必須依 L3 來源門檻完成事實確認後才能定案。

## 建議方案

建議 PostgreSQL 17，選定時鎖仍受支援的修補版。只定義新版候選；不將舊 MySQL 正式資料直接視為相容，也不操作現有 DB。

## 影響與驗收

本次 PostgreSQL 官方頁列 17.12 與 17 系列支援期限 2029-11-08。若涉及跨引擎資料接續，另驗證 UUID、日期時區、小數、排序、唯一性、鎖語意與關聯；依 M01–M03 選定範圍，不自動搬遷。真實 DB 的空庫重建、交易回滾與資源競爭驗收待開工後執行。資料庫選擇不綁 ORM 或認證方式。

## 依據與狀態

[PostgreSQL 版本政策](https://www.postgresql.org/support/versioning/)；[L3 來源與技術門檻](../L3_LEGACY_AND_TECHNOLOGY.md)。支持年限與修補版本是查核快照，不是已部署版本。
