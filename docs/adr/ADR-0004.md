# ADR-0004：新版資料存取採用 Spring Data JPA

- 核准日期：2026-11-17（Asia/Taipei）

- 主要任務：[Issue #4](https://github.com/xk2022/codex-xk-logistic/issues/4)
- 整體提案：[技術選型與資料接續建議](../TECHNOLOGY_AND_DATA_PROPOSAL.md)

## 背景與選項

候選為 JPA、JDBC 或 MyBatis；本庫 AGENTS 已將 Code First／JPA 列為優先，舊平台也有 JPA 經驗。新版多項目、多段及資源占用需要明確交易與併發設計，ORM 選擇不能代替這些規則。

## 已採用方案

採用 Spring Data JPA，關聯先使用清楚的外鍵識別，Request／Response 與 Entity 分開。Service 管理跨領域交易；列表用投影或明確查詢。需另套件的複雜查詢方案在證明需求後評估，不先新增第二套資料存取框架。

## 影響與驗收

已選定 JPA；正式 Entity、查詢與交易方案仍依關聯業務規格定稿後建立。針對版本衝突、同資源競爭、跨模組回滾和重送驗證；可評估 JPA 鎖模式與資料庫唯一約束的組合，但本 ADR 不定正式 schema 或預先核准業務釋放例外。依賴版本與選定 Boot BOM 核對；未執行 DB 或效能測試。

## 依據與狀態

[Spring Data JPA Locking](https://docs.spring.io/spring-data/jpa/reference/jpa/locking.html)；本 repo AGENTS 的資料存取規範。此選項與 DB、認證、Flyway 分開決策。
