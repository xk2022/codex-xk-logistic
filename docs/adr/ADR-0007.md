# ADR-0007：新版全新啟用，不接續本次詢問的舊 Truck 資料

- 狀態：Accepted
- 決策日期：2026-11-17（Asia/Taipei）
- 決策者：使用者陳祿元
- 主要任務：[Issue #4](https://github.com/xk2022/codex-xk-logistic/issues/4)

## 背景與依據

前輪已完成資料模型／草稿API契約，但D07尚未知是否有必須接續的資料。主AI詢問：「舊 Truck 是否有必須保留的客戶、訂單或照片？可回答有／沒有／待查。」使用者明確回答「沒有」。這是業務需求確認，沒有連線舊DB或查證舊庫是否空白。

## 決策與範圍

採M01全新啟用：新版以新建空資料庫及新資料開始，本次不匯入所詢問的舊客戶、歷史／在途訂單與照片，不建立相關來源映射、試遷、舊照片複製或雙寫工作。必要客戶及其他新版主檔以新版流程建立；本決策不授權從未確認的其他系統匯入資料。

保留已採用的PostgreSQL 17及Flyway。Flyway負責新版結構版本與空庫建立；「不匯入舊業務資料」不等於不需要schema migration或備份／還原驗收。開發驗收用明確標示的合成資料，測試fixture不作正式客戶資料。

本決策不包含刪除、停用、清空或改寫舊Truck、舊DB、舊照片及備份；未執行這些操作。沒有新增NAS／雲端資源、帳號、費用或正式部署。

## 對門檻與驗收的影響

- 本輪舊客戶／訂單／照片的接續需求已解除，不再要求它們的DDL、筆數、樣本、附件索引或搬遷來源作為首片輸入；未因沒有資料而宣稱已完成搬遷測試。
- L3-01僅就已詢問範圍記錄「無需接續」已確認；L3-06舊資料映射／照片對平，以及L3-07舊在途切換部分記為本路線不適用。新版派工唯一性／競爭測試仍保留。
- L3-05空庫建置與L3-08新版備份還原仍待實作驗證；不做舊庫回切演練不等於新版無需還原。
- G3仍須核對精確相依及執行環境；D02詳細權限、D04業務例外及D10維運等門檻保留。本次不核准產品程式開工或新安全政策。

## 選項與後續變更

M02主檔匯入＋歷史唯讀、M03歷史／在途接續保留作未來需求選項，目前未啟動。若日後另有車輛／司機等既有主檔或其他來源需要匯入，先提出具體範圍與來源，再做新的決策及映射驗收；本輪不替未知來源下結論，也不重問已回答的客戶／訂單／照片需求。

## 驗證狀態

本輪只同步決策與文件；無DB、Migration、資料匯入、產品測試、部署或刪除操作。文件差異、獨立審查、Commit／PR／main核對證據由主要Issue記錄。
