# Truck Platform × Logistics 新版功能差異矩陣

查核日期：2026-11-17（Asia/Taipei）。主要任務：[Issue #4](https://github.com/xk2022/codex-xk-logistic/issues/4)。

## 決策與證據基準

沿用經核對的業務邏輯另建新版：xk-truck-platform 是舊平台參考來源，codex-xk-logistic 是新版規格與實作 repo。[ADR-0001](adr/ADR-0001.md) 記錄方向，[決策清單](06-decisions-and-acceptance.md) 區分已確認基準及剩餘子項。

本次以舊平台固定版本 7b115c1f20bf723b3931f0547a34032e52649931 的完整目錄及 45 個檔案作靜態核對。[程式證據 E01–E12](SOURCE_CODE_AUDIT_20261117.md) 附固定版本檔案與行號。下表「有實作」只表示讀到方法與欄位，未代表建置、執行或產品驗收通過。

## 功能對照

| 領域 | 舊版靜態核對結果 | 新版需求／狀態 | 處理與剩餘缺口 |
|---|---|---|---|
| UPMS | 使用者管理、角色／權限及指派有 Controller／Service；有登入／本人／refresh 入口（E01、E10） | 單公司內部、管理員／調度員／司機三角色範圍已確認 | 沿用管理需求，重新實作認證及每筆資料授權；已採用 Session／CSRF；詳細授權／復原政策仍待確認 |
| ADM 字典 | 分類／項目 CRUD 與排序有實作；項目唯一約束的欄名與欄位宣告不一致（E02、E03） | 支援首版必要選項；字典清單尚未核定 | 參考語意重建；分類內唯一性、被引用資料異動及 DB 結構需驗收 |
| ADM 參數 | 只有核對到 upsert／依 key 讀取，不宣稱完整參數 CRUD（E02） | 所需參數與管理範圍待確認 | 新版定義型別、DTO、權限與異動規則 |
| CRM | 訂單保存 customerUuid／名稱快照；完整來源樹與本次讀取未找到獨立客戶管理模組（E05） | 客戶主檔為閉環需求候選，欄位／聯絡人深度待確認 | 沿用客戶識別與歷史快照語意；主檔功能新增；D07本次採M01，新版建新資料，無所詢問舊客戶匯入 |
| OrderCore | OPEN／CANCELLED／CLOSED 與終態守衛有領域方法，建立服務存在；跨任務結案閉環未核實（E06） | 延續高階生命週期；多段整單結案條件待定稿 | 重新實作跨模組交易、整單守衛與歷史 |
| TOM | 建立入口啟用；列表／明細／派單入口為註解。領域保有單一起終點、客戶快照與狀態方法（E04、E05） | 一單多項目／多段及ORD-P01～P03已確認；字典／作業例外仍待確認 | 保留 UUID／單號／類型／快照語意；重新建置多段模型及完整 API |
| 車輛／司機 | 主檔 CRUD／狀態、司機上下線、建立時車牌／電話檢查與 Entity 唯一約束存在（E07） | 沿用主檔及可用資源語意 | 重寫受派用資源的異動守衛、DTO 及授權；狀態轉移與併發驗收待做 |
| 派工 | assign 建立一筆；start／sign／complete／cancel 直接設定狀態；這組路徑未見足夠前態／本人／照片／占用／改派歷史檢核（E08） | 出發前可撤改留史，出發後走異常；作業完成且人車可離場後釋放，原則已確認 | 重寫派工狀態與原子占用／釋放、歷史及重送；確認人與例外子項待 D05／D09 |
| 多項目／多段任務 | ContainerInfo 只有櫃號／尺寸及長度檢查，RoutePlan 是空類別；DispatchTask 無獨立運輸任務欄位（E08、E09） | 每項目可多段，按前置條件執行；每任務最多一組有效派工，已確認 | 新建項目／任務／依賴／派工關係；無訂單任務、合載、板車分離仍待確認 |
| 司機手機 | 本次原碼／樹中未找到手機前端或本人派工手機閉環的完成證據 | 首版手機網頁與每段照片回報已確認納入 | 新版新增；詳細操作、代報／補件與實機支援待核定 |
| 照片資產 | 本次原碼／樹中未找到可證明私有照片上傳／驗證／存取閉環的流程；其他本機或外部來源待確認 | 每段作業照片回報已確認；格式、必填時點與保存細節未決 | 新增資產及授權流程；照片供應商、容量、備份與保存待 D06／D10 |
| API 契約 | 入口不完整；派工 Controller 直接回 Entity；既有路徑非統一 /api/v1（E04、E08、E10） | 首片五項草稿操作已有OpenAPI工程契約，未實作 | 按核定規格重寫 Request／Response、錯誤、分頁及動作契約 |
| 技術／相依 | POM 核對為 Java 21、Boot 3.5.7、JPA、MySQL driver 與 JWT；xk-truck 依賴 repo 內 xk-base（E12） | 已採用 Java 21／Boot 4.1.x、React／TypeScript／Vite、PostgreSQL 17、JPA、Session／CSRF 與 Flyway；精確版本待鎖定／驗證 | 採用記錄見 ADR-0002～0006；相依、空庫與執行整合仍待驗證；D07依明確回覆採M01，不推定舊DB現況 |
| 測試／交付 | 兩個 Java 測試檔：空斷言 AppTest、三個登入情境 AuthControllerIT；未找到業務測試、GitHub workflow 或版本化 migration 路徑（E11、E12） | 新版未建程式，無產品驗收通過證據 | 新增交易、授權、重送／競爭、API 與手機驗收；實際 CI／部署／還原另查 |
