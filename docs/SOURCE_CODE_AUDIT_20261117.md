## 可以沿用與必須重做

可沿用的是已確認的業務語意：訂單 UUID／單號與客戶快照、進出口／國內分類、Core 高階生命週期、車司機主檔、字典及角色管理需求。這些是設計輸入，不是新版可執行產物。

必須重做的是舊模型未表達或守衛不足的部分：多貨物／多段關係、任務前置條件、派工與歷史、狀態守衛、同一資源競爭、合法釋放、手機照片回報與權限、訂單整體結案，以及新的 API／資料結構／測試。

CRM、手機頁面、私有照片處理在這次原碼與完整樹中未找到足以證明已實作的流程；不排除未取得的本機、其他分支或外部系統，維持待確認。

## 完成與限制

本輪靜態核對可作 [功能矩陣](TRUCK_PLATFORM_TO_LOGISTICS_MATRIX.md) 的證據；產品執行、測試通過、正式部署、資料可用性、所有端點授權與安全狀態仍未驗證。下一開發切片及解鎖條件見 [新版交付切片](REBUILD_DELIVERY_SLICES.md)。
